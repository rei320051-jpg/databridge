# DS-004 展示与答辩数据源决策（已采纳：正式库主线）

> 提出：成员 3　日期：2026-10-04　关联：DS-001、F07、分工文档 §5.2.6 / §8 阶段交付
> 状态：**三人已同意（2026-10-04）——正式联调库 demo-v1.1 为演示/答辩主线，内置 85k 演示数据为现场保底。**

## 1. 决策内容

| 场景 | 数据源 | 模式 |
|---|---|---|
| 答辩演示主线 | **正式联调库 demo-v1.1**（2 万单，2026-01~09，sha256 锁定） | live：页面 → 成员 2 工作流 → 成员 1 FastAPI → SQLite |
| 现场故障保底 | 内置 85k 演示数据（2026-06~09） | mock：侧边栏一键切换，页面零改动 |
| 测试集回归（37+30 题） | 保持 85k 评分基准不变 | mock（测试的是页面管线回归，不随演示数据源切换） |
| 跨团队一致性锚点 | formal_dataset_test 35 项 | 正式库 expected.json 逐分一致 |

**规则**：同一场演示只使用一套数据；两套材料分文件存放，禁止数字混用。

## 2. 决策理由

1. 产品核心卖点是「可信」：F07 同数、manifest sha256 锁定、9 类异常质检拦截只有在正式库 + 真实三方链路上才是真实证据。
2. 正式库覆盖 9 个月，跨月退款、环比等素材更丰富；数字由确定性生成器产出并经 70 项校验 + 35 项跨团队一致性核对。
3. 现场风险可控：mock 模式开箱即用，服务不可用时侧边栏一键切换，不阻断演示。
