## 今天新增了什么（通俗版）

上一个阶段把数据存好、把怎么算说清楚。这次让其他程序能够发一个请求，拿到真实的计算结果。

1. 加入查询执行器：接收指标、日期和筛选条件，执行数据库查询。它能算5个指标，也能按地区或客户类型拆分结果。
2. 加入HTTP接口：提供统一的调用入口。页面或AI后续接入时，可以调用同一份计算逻辑。
3. 加入结果依据：每次查询保存请求、SQL模板、参数、结果与耗时；返回结果注明口径和版本。
4. 加入错误处理：请求错误、覆盖不足、数据版本不存在、数据库失败、超时及尚未支持的比较，都有明确状态。
5. 实际启动服务并调用：客户端真的通过本机HTTP发请求，结果正确，测试后自动停止服务。
