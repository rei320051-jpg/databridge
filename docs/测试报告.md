## 4. 关键实验结论

### 4.1 S1 直接 Text-to-SQL vs S2 完整治理（开发集 37 题）

| 指标 | 85k mock | **正式库 demo-v1.1（主线）** |
|---|---|---|
| S1 完成率 | 0/37 = 0% | **0/37 = 0%** |
| S2 完成率 | 37/37 = 100% | **37/37 = 100%** |
| S1 数值错误 | 20 题 | 21 题 |
| S1 无依据编造（该拒答却作答） | 9 题 | 8 题 |
| S2 正确澄清 | 8 题 | 8 题 |

> v1.2（2026-10-04）计数变化：D27「退款率」随派生指标落地由拒答改为时间澄清
> （S2 正确澄清 7→8；mock 侧 S1 数值错误 21→20）；正式库另因 D24 改判 success，
> S1 编造 9→8。判定总数仍为 37×2，结论不变。

- 正式库 S1 虚高实例：9 月净销售额报 **18,166,729.12 元**，真实 **17,198,835.91 元**，
  虚高 **967,893.21 元（+5.63%）**——SQL 能跑不报错。
- 正式库数值错误独立归因：未排除失败/取消订单 18 题、JOIN 一对多扇出 16 题、退款按支付月归属 13 题。
- 诚实声明：S1 为**确定性行为基线，无真实 LLM 调用**；成员 2 接入真实模型后需用同一模型重测。

### 4.2 IS-001 退款时间归属（正式库真实测量）

- 成功退款 3,062 笔中跨月 1,356 笔（**44.28%**），金额 6,176,762.17 元（**45.55%**）。
- 若按订单支付月归属（S1 口径），2026-09 华东被**回溯改写 329,335.21 元（−4.82%）**；
  按退款完成月归属（现行 S2）历史月份零漂移。
- 守恒校验：两口径全期总额相等、差异矩阵逐格等于逐笔退款独立重算。
- 建议维持方案 A（refund_time）；**三人已于 2026-10-06 签字冻结**（见 `docs/口径冻结确认单_2026-10-04.md`）。

### 4.3 跨团队一致性（F07）

- 页面管线在正式库上：9 月总净销与五地区净销对 expected.json **差值全为 0 分**；
  分地区之和 = 汇总；跨月（3 月）覆盖一致；超额退款 0 例；跨地区客户按订单快照处理。
