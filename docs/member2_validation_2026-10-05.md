## 缺陷与修复证据

新增测试先在基线上失败，再实施修复。初始13项用例复现派生拒答/映射缺失、日期区间只查首日、错误年份、非法日期异常、丢失澄清条件、模型结构异常、排名和比较被忽略。

独立只读代码审查发现并复核修复：

1. 中文/省略年份/混合年份的多个日期比较只能执行第一期：现在完整区间优先，多期明确拒答，不返回部分数字。
2. 经营简报行缺少 growth_rate 会错误排除最差地区：现在缺字段是失败；合法 null 仍表示基期不可比较。
3. 无比较基期的“增长率”被当成基础指标：现在明确要求完整自然月环比；明确9月与上月比较采用9月为本期。
4. 专属指标同义词被短子串命中造成多问一轮：忽略被更长同义词完整包含的命中，独立出现多个指标仍澄清；全部共享同义词通过。

5. 未定义“净销售额比率/退款金额比率”曾返回基础金额：现在明确拒答，合法共享“退款比率”仍查询退款率。

其他负面覆盖：分母零/退款独有分组、双分量任一失败、追溯失败、畸形模型计划/响应、恶意排名上下文、HTTP错误成功信封、简报截断。

## 证据边界

测试数量不是业务问题准确率；模型真实准确率、成本、时延均未测。没有另一台电脑部署验证。Starlette 1.7.0 对原 httpx TestClient 有弃用提示，来自现有锁定依赖，真实 HTTP 用例通过。页面上传/激活未改，不能据此称完整产品上线。

自然语言比较枚举沿用冻结 `none/mom`；不支持同比或任意两期比较，返回 out_of_scope。三派生指标在 Agent 层组合，执行器原生 /v1/query 五指标契约保持不变。
