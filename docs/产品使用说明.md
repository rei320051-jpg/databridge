# 产品使用说明

> 版本 v1.0 · 2026-10-04 · 成员 3 整理
> 目标：**第一次接触本产品的人，按本说明可以在 5 分钟内独立完成一次可信取数查询**（对应分工文档 §5.4 验收标准第 1 条）。

## 1. 这是什么产品

**数桥 DataBridge · 可信取数平台**——面向 AI Agent 的零售订单分析取数平台。

核心承诺：**每一个数字都附带指标口径、来源表、数据集版本和可追溯的查询记录；当数据无法支持结论时，平台明确说明缺什么，而不是编一个答案。**

| 你可能关心 | 平台的回答方式 |
|---|---|
| 数字怎么算的？ | 每次查询展示口径定义（如：净销售额 = 实付金额 − 成功退款） |
| 数字来自哪里？ | 展示来源表、数据集版本、查询编号和 SQL |
| 问题描述不清？ | 先澄清，最多追问 2 轮，不会猜 |
| 数据不够回答？ | 明确拒答并说明缺什么，不会编造 |

## 2. 启动

```powershell
# 已按 README §1.1 安装过依赖的机器，只需一条命令
.venv\Scripts\python.exe -m streamlit run app/app.py
```

浏览器自动打开 `http://localhost:8501`。**页面开箱可用**：首次运行自动生成内置演示数据（85,018 条订单），无需先准备数据文件、无需启动任何后端服务。

（可选）想对接成员 1 的正式查询服务时：先按 README §1.3.1 启动 FastAPI，再在页面左侧栏把「后端模式」切到 `live`，点「测试连接」确认服务可达。

## 3. 完成一次查询的完整路径

页面共 5 个标签页，自左向右就是推荐操作路径：

### 第 1 步 · ① 数据接入 —— 选一份数据

- 页面主体选择数据源：
  - **内置演示数据**（8.5 万单，2026-06 ~ 09，5 地区）——默认，直接可用；
  - **正式联调库 demo-v1.1**（2 万单，2026-01 ~ 09，5 地区）——成员 1 交付、sha256 锁定的正式数据。
- 切换数据源会清空历史查询，两套数据**口径一致、数字独立，不可混用**。
- 查看数据概览与**质量检查结果**（金额范围、状态码、退款不超实付等）；本页也可勾选载入「异常数据集」体验质检拦截。
- 左侧栏随时可见契约状态：接口契约版本、数据集版本、数据覆盖区间、功能冻结日。

### 第 2 步 · ② 业务字典 —— 核对口径（推荐，可选）

- 逐项查看 5 个核心指标的定义、计算规则和同义问法（例如「实付金额 = 成功订单的实际支付金额，退款不计入」）。
- 勾选「我已确认」记录你的核对进度；**不确认也不阻断查询**，平台只会在提问时温和提醒。
- 口径理解不一致是取数结果互相矛盾的最常见原因，建议评委演示前完成这步。

### 第 3 步 · ③ 智能取数 —— 提问

- 在输入框用自然语言提问，例如：`2026年9月各地区的净销售额环比对比`，点「提问」。
- 不知问什么？点下方 5 个**快捷示例**（同时是接口自测用例，每个都标注预期状态）。
- 可能出现三种回答：
  1. **成功**：结果表 + 关键指标卡片；如有数据质量警告（如结果截断）会一并展示；
  2. **需要澄清**：出现黄色提示与选项（如「GMV 是指实付还是净销售额？」），点选或输入文字说明，最多 2 轮，之后宁可降级为拒答也不猜；
  3. **明确拒答**：如问「2026年3月净销售额」而当前内置演示数据只覆盖 6–9 月，会返回「数据不足」并说明缺失范围，不会编数字。
- 页面保留最近 30 轮对话，可随时回看。

### 第 4 步 · ④ 结果依据 —— 验证每个数字

- 展示本次查询的**编号、状态、执行时间**；
- 成功查询展示完整证据链：指标口径、单位、时间范围、来源表、数据集版本、**生成的 SQL 与参数**、退款扇出防护说明等；
- 拒答/澄清也会展示原因码，便于复核。

### 第 5 步 · ⑤ Agent 调用回放 —— 看 AI Agent 怎么用这个平台

- 点「运行示例运营 Agent：生成 2026 年 9 月经营简报」；
- 展示 Agent 的六步调用过程（接收任务 → 调用接口 → 取环比 → 找降幅最大地区 → 形成分析 → 标明口径与限制）、结果表、自动生成的经营分析文字、分析依据与分析限制。

## 4. 常见问题

| 问题 | 说明 |
|---|---|
| 为什么不直接给个数字？ | 数据覆盖不到提问区间、或口径无法确定时，平台按契约返回「数据不足 / 需澄清」并给出原因码，这是产品设计，不是故障。 |
| 两套数据源数字为什么不同？ | 内置演示数据与正式联调库是**两份独立数据**，仅物理约定（规模、单位呈现）不同、口径一致。同一场演示请只用一套。 |
| live 模式连不上？ | 确认成员 1 的服务已启动且地址正确（默认 `http://127.0.0.1:8000`），或切回 mock 模式继续体验全部流程。 |
| 结果只显示部分行？ | 结果表最多预览 200 行，超出会给出截断警告并提供下载。 |
| 想重新开始？ | 左侧栏「清空对话与查询记录」。 |
