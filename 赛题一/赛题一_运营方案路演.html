01

核心打法：就做三件事

内容复用赛题二成果，不另起炉灶
第一件

做钩子

  • 准备期把赛题二的数据集、Prompt、Demo 打包上架为制品
  • 落地页首屏直接放「可认领的真实任务 + 领取按钮」
  • 全队自己走一遍：看到 → 注册填码 → fork，不卡才算过
准备期完成
第二件

发内容

  • 固定 「3+1」节奏：每周 3 条小红书 + 1 篇技术实操文
  • 1 条 60 秒视频，B 站 / 视频号 / 朋友圈多处复用
  • 赛题二成果跑通即首发，当天全员转发
第三件

看数据

  • 每天固定时间记一行飞书表，按周轮值
  • 每周一次 30 分钟周会，砍掉无效渠道
  • 收口期只保留转化最好的 2 个渠道
02

目标人群：主攻一类，兼顾一类

主攻

会写代码 / 搭 Agent 的人

动机
给 Agent 找真实场景，接单、交付、通过系统评分
卖点
你的 Agent 能接真实的活，不是玩具 Demo
渠道
掘金或知乎（选一个）、技术社团群、B 站
兼顾

要数据、找实习的同学

动机
毕设竞赛缺正规数据、简历缺作品
卖点
央企背书的行业数据集 + 作品公开曝光
渠道
学院群、导师、朋友圈、小红书

判断依据：报名结束后校内泛流量已过峰，技术人群自带动机、转化率最高；兼顾人群只在顺手渠道覆盖，不撒胡椒面。

03

发什么、在哪发

渠道内容频次
朋友圈 / 微信群海报 + 一句话文案全队定期转发
小红书教程 / 比赛收获 / 演示图文（正文零外链，评论区引导）3 条 / 周
掘金或知乎技术实操长文，如《零代码 10 分钟，让会接单的 Agent 上线》1 篇 / 周
B 站 / 视频号60 秒演示视频（一次录制，多平台复用）每周有更新
学院群 / 导师海报 + 赛事说明放量期集中推

明确不做：不投信息流广告、不买粉、不做现金抽奖——这类注册在邀请码口径下是无效增长，还可能违规。

04

阶段排期：以提交日倒排

与赛题二冲突时，先保赛题二核心实现
准备期第一步
  • 向组委会确认：邀请码何时上线、能否看渠道来源、转发能否统计
  • 注册各平台账号，建好飞书记录表
  • 赛题二制品上架，跑通「注册 → fork」全链路；海报 + 落地页完成
验收：自己点一遍链路无卡点
试水期约一周
  • 小红书、实操文、视频各小批量发布
  • 每天记数据，找出带量的内容类型和渠道
产出：真实基线，据此定放量期目标
放量期约一周
  • 按「3+1」节奏持续发布；学院群 / 导师集中推送
  • 赛题二成果跑通即首发，全员转发（赛期最大一波）
  • 每周淘汰无效渠道，加码有效渠道
标志：有效渠道稳定带来注册
收口期提交前数天
  • 只留转化最好的 2 个渠道；后台截图归档；完成复盘
标志：材料齐全，按时提交
05

转化漏斗：只定口径，不拍数字

目标在试水期拿到基线后再定
曝光
内容被看到平台后台阅读 / 播放量
点击
点进引流链接分渠道短链 / 落地页
注册
填写队伍邀请码组委会邀请码后台归因
激活
7 日内有真实动作发布 / 认领 / fork / 互动
转发
一键转发朋友圈制品页 / 平台统计

等宽灰条仅为环节示意，不代表任何数值；归因以用户首次进入的队伍专属入口为准，重复访问不重复归因。目标在试水期拿到基线后再定，复盘时目标与实际照实对比——承认偏差不扣分，材料缺失才扣分。

记录方式：一张飞书表，每天固定时间由轮值同学填一行。
日期渠道内容链接 曝光新增注册备注（异常 / 改版）
06

投入与产出

海报 / 打印物料小额现金 · 按需印制
易拉宝优先借用，不足再买
换量小周边少量 · 社团互推用
落地页 / 域名¥0 · GitHub Pages
API / 算力 · 场地平台免费额度 + 学院借用
现金原则压到最低，以资源置换为主
数联开放日的照片与见闻是第一批现成素材；内容全部复用赛题二材料，不额外生产。

一份投入，四项产出

  1. 真实流量证据：各平台后台 + 邀请码后台截图，按周归档
  2. 平台制品：赛题二数据集 + 可复用的运营 SOP
  3. 数据记录与复盘：飞书表导出 + 一页复盘
  4. 平台功能建议：走查后的真实建议清单（见 07）
保底：即使流量数字一般，制品、截图、复盘照样成立，不依赖赌单一数字。
07

风险预案 与 平台建议

最可能遇到的 3 个风险

R1
邀请码上线晚 / 看不到渠道来源
各渠道用不同短链区分；落地页加「从哪知道我们」单选项兜底；准备期第一时间问组委会。
R2
小红书对导流内容限流
正文零外链，只走评论区与主页；被限就转 B 站和公众号，不硬刚。
R3
被赛题二挤占、内容断更
只发复用赛题二的内容，提前存少量备发；最差只保朋友圈 + 技术社区。

P0
注册登录
支持 GitHub / 微信一键登录；邀请链接点开自动带码，免手填。
P1
新手引导
注册后立刻给一个几分钟能完成的示例任务 + Agent 模板。
P1

08

5 分钟路演：做了什么 → 带来了什么 → 怎么放大

数字只用真实台账，不用预估
第一段 · 约 1.5 分钟

做了什么

  • 赛题二成果上架为 DataClawHub 制品（注册后可 fork）
  • 落地页 / 海报，全队走通专属邀请码链路
  • 按「3+1」节奏在多个渠道发布内容
现场可演示全链路
第二段 · 约 2 分钟

带来了什么

  • 专属链接访问 __ · 邀请码注册 __
  • 7 日激活 __ · 制品 fork / 互动 __
  • 最有效的渠道与内容，后台截图佐证
执行期据实填，不编数
第三段 · 约 1 分钟

怎么放大

  • 加码已验证的 2 个渠道
  • 把跑通的运营 SOP 交给更多队伍复用
  • 按平台建议清单推动产品改进

若提交时执行期数据尚不完整：如实展示已完成的真实动作与现有基线，说明其余指标在统一实测期继续验证，不用预估数冒充结果。

提交前自检

  • 方案七块齐全：目标画像 / 内容 / 渠道 / 排期 / 成本产出 / 风险 / 平台改造

  • 数据复盘：目标 vs 实际、有效 / 无效动作、下一轮想法
  • 平台上有可访问的赛题二制品，且「注册后方可 fork」走通过
  • 内容全部原创或已授权，外部引用标注出处
  • 路演讲清：做了什么 → 带来了什么 → 怎么放大
