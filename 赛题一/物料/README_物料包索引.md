## 发布前必做的 3 处替换（邀请码到手后）

1. **落地页**：`落地页_index.html` 中两处 `href="#invite-soon"` → 队伍专属邀请链接；删除"即将开通"提示。
2. **海报**：`海报_朋友圈.html` 中 `TEAM-XXXX（待替换）` → 真实邀请码；二维码占位框替换为真实二维码图片（建议 210×210）。
3. **文案**：`内容素材包.md` 中所有 `【落地页】`、`【制品链接】`、`【技术长文链接】` → 真实 URL。
