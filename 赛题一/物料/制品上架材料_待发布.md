## 4. 制品正文（可直接粘贴）

### 这是什么

**数桥 DataBridge** 是一个面向 AI Agent 的可信取数平台，解决一个具体问题：让 AI 查业务数据时「先确认口径、覆盖不够就拒答、每个数字可追溯」，而不是一本正经地给出虚高数字。

制品包含三件套，fork 后归到你自己账号：

1. **演示数据集（demo-v1.1）**：20,000 笔订单 / 3,492 笔退款 / 2,000 个客户，覆盖 2026-01 至 2026-09，内置 9 类异常数据固件（负金额、超额退款、重复主键、坏时间戳、外键缺失等），数据版本由内容哈希锁定。
2. **提示词与契约**：5 个基础指标 + 3 个派生比率指标（退款率 / 客单价 / 支付人均消费）的口径定义、查询计划 JSON Schema、澄清话术，拿到就能接自己的模型。
3. **可运行 Demo**：Streamlit 产品页 + FastAPI 只读服务，Python 本地几分钟跑通，附使用说明；同时提供规则模式（离线、可复现、零成本）与真实大模型模式（OpenAI 兼容接口，密钥只从环境变量读取）。

### 实测结果（均可由仓库内测试脚本复算，非宣传话术）

- **开发集 37 道真实业务题：37/37 全部答对**；对照的普通 Text-to-SQL 方案完成 0 题——同一道「2026 年 9 月销售额」，错误方案给出 18,166,729.12 元，正确净销售额为 **17,198,835.91 元**，虚高 967,893.21 元（+5.63%）。
- **真实大模型复测（DeepSeek，开发 37 + 保留 30 共 67 题）：67/67 与规则模式逐字段一致，0 编造、0 越界作答**；其中 13 道因果 / 预测 / 写操作类问题在调用模型前即被本地护栏拦截；54 次模型调用、平均 0.93 秒、总花费约 0.023 元。
- 比率指标遵守"先汇总分子分母再相除"，分母为零返回 null；退款按退款完成时间归属期间；每个派生结果附 components 溯源字段。

### 三步上手

1. 在 DataClawHub 注册并 fork 本制品（或从 GitHub Release 下载提交包）；
2. 一条命令装依赖、一条命令起服务（README 有 Windows / macOS 说明）；
3. 打开页面提问：问「9 月销售额」它会先反问净销还是实付；问「业务为什么下滑」它明确拒绝编造；每条结果都能展开 SQL、参数与数据版本溯源。

### 边界说明（如实）

- 数据为**模拟演示数据**，任何数字不代表真实经营情况；
- 自然语言比较仅支持完整自然月环比，同比 / 任意两期比较明确拒答；
- 结论仅覆盖数据声明的时间区间，不做因果推断与预测；
- 自定义 CSV 可经质检与导入脚本使用，平台首版不支持任意上传文件的自动激活。
