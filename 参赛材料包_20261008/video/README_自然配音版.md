# 自然配音替换版

本版用 AI 生成的 Microsoft Edge 神经语音 `zh-CN-XiaoxiaoNeural` 替换原 Windows SAPI 系统旁白。语速设为 `-8%`，保持正常音高，逐句对齐原分镜；仅在语音超过镜头可用时间时做小幅时间压缩，不截断句子。

所用技能：[edge-tts](https://github.com/aahl/skills/tree/main/skills/edge-tts)。使用原已选 Python 虚拟环境运行 `python -m edge_tts`，不另建环境、不修改 requirements。本次试听确认服务可用；失败时停止，不再回退到机械系统声。

## 推荐交付文件

- `赛题二_演示视频_自然配音_软字幕.mp4`：原产品演示画面、原可切换字幕、原自然旁白，v2 重封装。
- `赛题二_演示视频_自然配音_硬字幕.mp4`：原产品演示画面、v2 增强字幕、原自然旁白。
- `赛题二_演示视频_自然配音.srt`：与原外挂字幕完全一致。
- `赛题一_演示视频_自然配音_软字幕.mp4`：原运营方案画面、原可切换字幕、原自然旁白，v2 重封装。
- `赛题一_演示视频_自然配音_硬字幕.mp4`：原运营方案画面、v2 增强字幕、原自然旁白。
- `赛题一_演示视频_自然配音.srt`：与原外挂字幕完全一致。

两支视频时长与旧版一致，分别为四分半和四分四十五秒。v2 软字幕版复制原视频、AAC 及字幕数据包；硬字幕版从原无字幕画面重新烧录，视频须重新编码，AAC 原样复制。文案、字幕文本、字幕时间轴、数字口径和 rules 模式录屏不变。旧系统配音的四个 MP4 已按用户要求删除，不重新生成；既有 ZIP 和项目源码未修改。

## v2 字幕样式与仅重合成

硬字幕在 1920×1080 下使用 40px 微软雅黑、2.5px 黑描边、底部居中以及 70% 不透明的黑色底条；白名单数字及相邻单位用金黄 `#F5B800`。原文“2 万订单”不替换为“20,000 订单”，高亮只命中白名单实际出现的写法。

libass 的字号单位按字体行高计算，不等同于 CSS 像素字号。实测当前微软雅黑 40px 的上升/下降度量为 43/11px，因此 ASS 使用 54 行高单位，以保持 40px 字体尺度，PlayRes 固定为 1920×1080。[libass 字体度量实现](https://github.com/libass/libass/blob/master/libass/ass_font.c)

软 MP4 继续包含可切换的 mov_text 字幕，文本与时间轴数据包完全保持原样；SRT 也按原字节重导出。mov_text/SRT 的最终显示由播放器决定，统一的描边、黑条和数字颜色以硬字幕 MP4 为准。

```powershell
$videoPython = (Resolve-Path '赛题二/.venv/Scripts/python.exe').Path
$env:PYTHONDONTWRITEBYTECODE = '1'
& $videoPython '参赛材料包_20261008/video/自然配音替换.py' --preview-v2
& $videoPython '参赛材料包_20261008/video/自然配音替换.py' --compose-v2
```

这两个入口只读取现有软字幕 MP4、原 SRT 与素材，不调用录制或 TTS。`--compose-v2` 重合成并自检两支作品，更新六张 QA 和 v2 报告；无需旧系统配音成片。运行前确保原录制中间素材仍在本地，以便核对素材哈希。

`自然配音_验收报告.json` 记录每镜语音时间、引擎、音色、压缩比例、字幕与画面包哈希一致性、分辨率、时长和音量自检。此报告不冒充人工听审：自然程度和专有名词读音还可以通过试听复核。

`自然配音替换.py` 的默认入口是历史配音替换流程，依赖已删除的旧成片，不要直接运行。当前只使用上述 `--preview-v2` / `--compose-v2` 渲染入口。合成中的 PCM WAV 与原始神经语音片段仅在本地保存，最终 MP4、SRT、说明和报告随本分支发布。

v2 报告按当前成片重新记录哈希、响度、编码和抽帧，另以源视频/声音/软字幕数据包哈希、素材哈希和字幕区外 SSIM 核对“只动渲染层”。历史配音阶段的逐句语音元数据保留，不把历史验收状态误写为本次所有成片未变。
