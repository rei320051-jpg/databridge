# 自然配音替换版

本版用 AI 生成的 Microsoft Edge 神经语音 `zh-CN-XiaoxiaoNeural` 替换原 Windows SAPI 系统旁白。语速设为 `-8%`，保持正常音高，逐句对齐原分镜；仅在语音超过镜头可用时间时做小幅时间压缩，不截断句子。

所用技能：[edge-tts](https://github.com/aahl/skills/tree/main/skills/edge-tts)。使用原已选 Python 虚拟环境运行 `python -m edge_tts`，不另建环境、不修改 requirements。本次试听确认服务可用；失败时停止，不再回退到机械系统声。

## 推荐交付文件

- `赛题二_演示视频_自然配音_软字幕.mp4`：原产品演示画面、原可切换字幕、新旁白。
- `赛题二_演示视频_自然配音_硬字幕.mp4`：原已烧录字幕的画面、新旁白。
- `赛题二_演示视频_自然配音.srt`：与原外挂字幕完全一致。
- `赛题一_演示视频_自然配音_软字幕.mp4`：原运营方案画面、原可切换字幕、新旁白。
- `赛题一_演示视频_自然配音_硬字幕.mp4`：原已烧录字幕的画面、新旁白。
- `赛题一_演示视频_自然配音.srt`：与原外挂字幕完全一致。

两支视频时长与旧版一致，分别为四分半和四分四十五秒。视频流直接复制，不重新录制或降质；文案、字幕文本、字幕时间轴、数字口径和 rules 模式录屏不变。旧系统配音的四个 MP4 已按用户要求删除，当前只保留自然配音成片；既有 ZIP 和项目源码未修改。

`自然配音_验收报告.json` 记录每镜语音时间、引擎、音色、压缩比例、字幕与画面包哈希一致性、分辨率、时长和音量自检。此报告不冒充人工听审：自然程度和专有名词读音还可以通过试听复核。

`自然配音替换.py` 保留本次替换所用配置与代码。该脚本依赖旧成片作为画面输入；旧视频清理后，不可直接重跑。需要重新制作时，应先准备画面输入并沿用此处的神经语音配置，不要重新交付系统配音版。合成中的 PCM WAV 与原始神经语音片段仅在本地保存，最终 MP4、SRT、说明和报告随本分支发布。

自然配音报告中的“原有跟踪文件未修改”描述的是替换完成时的验收状态。本次后续清理另有用户明确授权，只移除了旧成片并更新交付说明；既有录屏证据、字幕依据和历史验收记录保留。
